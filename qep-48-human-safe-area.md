# Summary

Create a "AI Free", "Human Safe Area" for QGIS community human beings to interact.

Introduce a full ban for AI generated content in all QGIS github repositories, pages, wikis etc.

This includes any text that was (until AI came into the games) supposed to be generated and entered by human beings.

Note that this **does not cover the source code itself**, which is regulated by another QEP 408: https://github.com/qgis/QGIS-Enhancement-Proposals/blob/master/qep-408-ai-tool-policy.md

## Why

AI generated content has begun to appear in the comments and in the text of PRs and human beings are now never sure if they are interacting with a machine or with another human being.

This creates a problem with trust and human beings have begun to be suspicious when they read content (comments, PR text etc.) on github.

## Proposed Solution

Change the landing page of the repositories to clearly state that they are a "Human Safe" "AI Free" zone and that AI generated text are not allowed.

## Deliverables

Text added to the README.txt in each repository.
